For Loop

Definition: For loop in javascript is the most commonly used loops to repeat a block of code a specific number of times Syntax: for(initialization; condition; increment/decrement) { //code to be executed; } Initialization -> Run once(start value) Condition -> Checked before each iteration Increment/Decrement -> update loop variable Example: Crorepathi - the Length of the iterations is KNOWN

While Loop

Definition: The while loop executes the set of statements as long as the condition is true. Condition checked before execution. If condition is false initially -> loop won't run. Syntax: while (expression) { Statements to be executed if expression is true } Example: Currency Evaluator - the length is unknown it will run as long as it is false

do..while Loop

Executes at least one time even if the condition is false. while - condition false - does not run do.. while -> run once -> execute at least once Syntax: do { statement to be executed; increment; } while (expression) Example: OTT Platform - where the 1st episode will run before we subscribe

For-in Loop

The for-in loop is used to loop through object properties. In each iteration, one property from object is assigned to a variablename and this loop continues till all the properties of the object are exhausted. Syntax: for (variablename in object) { statement or block to execute }
